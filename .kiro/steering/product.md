# Product Overview

バドミントンダブルスのコートメンバー割り当てをランダムかつ公平に行うWebアプリケーション。サークル活動での「誰がどのコートに入るか」問題を解決し、参加者全員が均等にプレイできるよう最適化する。

## Unique Value（他にない機能）

**「試合回数を確認しながらメンバー調整できる」** - これが本アプリ最大の差別化ポイント。

- 一般的なアプリ: ランダムに組み合わせを生成するだけ。不公平が生じても調整不可
- 本アプリ:
  - 各メンバーの試合回数・連続休憩回数・総休憩回数をリアルタイム表示
  - ドラッグ&ドロップで直感的にメンバー入れ替え
  - **調整と同時に統計情報が即座に更新**され、公平性を確認可能
  - 不公平な状態（連続休憩や試合回数差など）を視覚的に警告（閾値は動的計算）

## Core Capabilities

- **メンバー自動生成**: 参加者数とコート数から各コート4人のダブルス構成を自動生成
- **履歴ベースの最適化**: 過去の組み合わせとの編集距離を計算し、類似組み合わせを回避
- **プレイ回数の平準化**: 2つのアルゴリズム（ばらつき重視 / 均等性重視）から選択
- **リアルタイム共有**: URLで共有、7日間有効、LINE共有対応
- **プッシュ通知**: 共有画面を閉じていても重要イベント（生成、参加、離脱）を通知
- **途中参加・離脱**: 試合中のメンバー増減に対応

## Target Use Cases

- バドミントンサークルでのコート割り当て（週1〜2回の定期活動）
- 時間内に複数回ゲームを行う際のローテーション管理
- 途中参加・途中退出メンバーへの柔軟な対応
- 参加者全員への結果即時共有

## Value Proposition

- **公平性の可視化**: 統計情報をリアルタイム表示し、運営者が状況を見て判断可能
- **不公平の自動検出**: 連続休憩や試合回数の偏りを警告表示
- **多様性**: 同じ組み合わせが繰り返されにくい設計
- **シンプルさ**: 専用アプリ不要、ブラウザのみで動作
