### ロジック層の実装（TDD）

- [x] 1. 警告計算ロジックの実装
- [x] 1.1 警告閾値計算のテスト作成
  - 各パラメータ組み合わせでの閾値計算テストを作成する（2コート10人→閾値2、4コート24人→閾値3等）
  - アルゴリズム補正のテストを作成する（ばらつき重視: +1、均等性重視: そのまま）
  - 休憩人数が0以下の場合のエッジケーステストを作成する
  - 閾値の最小値制約（1以上）のテストを作成する

- [x] 1.2 警告閾値計算機能の実装
  - テストを通すために閾値計算ロジックを実装する
  - 確率論的アプローチで基本閾値を計算する（ln(α) / ln(p) の公式を使用）
  - アルゴリズムに応じた補正を適用する
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 1.7_

- [x] 1.3 警告検出のテスト作成
  - 連続休憩警告の境界値テストを作成する（閾値ちょうど、閾値-1、閾値+1）
  - 試合回数差警告の境界値テストを作成する
  - 補正値が正しく適用されることのテストを作成する
  - 警告状態オブジェクトの構造テストを作成する
  - _Requirements: 2.1, 2.2, 2.3, 3.1, 3.2, 3.3_

- [x] 1.4 警告検出機能の実装
  - テストを通すために警告検出ロジックを実装する
  - 各メンバーの連続休憩回数を取得し、閾値と比較して警告を判定する
  - 試合回数差を計算し、閾値以上の場合に最少メンバーを警告対象とする
  - _Requirements: 2.1, 2.2, 2.3, 3.1, 3.2, 3.3_
