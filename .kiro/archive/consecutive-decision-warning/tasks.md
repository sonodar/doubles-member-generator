# Implementation Plan

## Tasks

- [x] 1. 連続操作検出ロジックの実装
- [x] 1.1 (P) 連続操作判定関数を作成する

  - 現在時刻との差分が60秒未満かを判定する
  - 履歴が空の場合は false を返す
  - 時刻パース失敗時は安全側に倒し false を返す
  - テスト容易性のため現在時刻をオプショナルパラメータとして受け取る

- [x] 1.2 (P) 連続操作判定関数のユニットテストを作成する

  - 履歴あり・1分以上で false を返すケース
  - 履歴なしで false を返すケース
  - 不正な時刻フォーマットで false を返すケース
  - _Requirements: 1.1, 1.2, 1.3, 5.1_
