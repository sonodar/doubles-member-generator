# [バドミントンダブルスメンバー決めるくん](https://badminton.sonodar.net)

バドミントンサークルや友人同士の集まりで、複数のコートを使ってダブルス試合を行う際に、参加者全員が公平に試合を楽しめるようにメンバーの組み合わせを決めるアプリケーションです。

## このアプリだけの特徴

**「試合回数を確認しながらメンバー調整できる」** - これは市場で唯一無二の機能です。

| 一般的なアプリ | このアプリ |
|--------------|-----------|
| ランダムに組み合わせを生成するだけ | 各メンバーの試合回数・休憩回数をリアルタイム表示 |
| 不公平が生じても調整不可 | ドラッグ&ドロップで直感的にメンバー入れ替え |
| 統計情報なし | 調整と同時に統計が更新され、公平性を即座に確認 |
| 警告機能なし | 連続休憩3回以上などの不公平を視覚的に警告 |

## 解決する課題

- メンバーの組み合わせを手動で決めるのが面倒
- 毎回同じメンバーと試合をしてしまう
- 特定の人だけ試合回数が多い・少ない
- 誰が何回試合をしたか覚えておくのが大変
- 複数コートで同時進行する際の管理が複雑

## 基本的な使い方

### 初回設定

1. アプリケーションにアクセス
2. コート数を選択（1〜4面）- ラジオボタンで選択
3. 参加人数を設定（8〜32人）- スライダーまたは±ボタンで調整
4. 組み合わせ方式を選択（ばらつき重視 / 均等性重視）
5. 「開始」ボタンで試合運営を開始

※一度開始したらコート数は変更不可（やり直す場合は最初から）

### 試合運営

1. 「メンバー決め」ボタンを押す
2. 自動生成された組み合わせを確認
3. 必要に応じてドラッグ&ドロップで調整
4. 「確定」で試合開始
5. 試合終了後、1に戻る

### 途中参加・離脱

- 「参加」ボタン: 人数を増やす（最大32人まで）
- 「離脱」ボタン: 離脱するメンバー番号を選択して人数を減らす
- 次の組み合わせから反映
- 現在試合中のメンバーは離脱不可

## 主な機能

### メンバー組み合わせの自動生成

- 各コートに4人ずつ配置、余った人は休憩
- 過去の組み合わせと同じにならないよう最適化（最大10回再生成）
- 10回試しても新しい組み合わせが作れない場合は警告表示
- 2つのアルゴリズムから選択可能

### 手動調整（最重要機能）

- ドラッグ&ドロップでメンバー入れ替え（タッチ操作対応）
- コート間でメンバーを入れ替え
- 休憩メンバーと試合メンバーを入れ替え
- 移動と同時に全メンバーの統計が再計算
- 不公平な状態を赤色で警告表示
- 各コートは必ず4人（空きコートは作れない）

### 統計・記録

- **試合履歴**: 時系列表示（新しい順）、各コートのメンバー構成と休憩メンバー
- **総プレイ回数**: メンバー別一覧、多い順に色分け（赤:多い、黄:普通、緑:少ない）
- **連続休憩回数**: 2回以上連続の場合は警告色で表示
- **総休憩回数**: 累計休憩回数、休憩が多い人を目立つように表示

### 不公平の警告機能

以下の条件で警告を表示:
- 特定メンバーが3回連続で休憩
- 試合回数の差が3回以上
- 同じペアが3回以上組んだ

### 共有機能

- **共有リンク**: 固有URL発行、QRコード表示対応
- **LINE共有**: 組み合わせ結果をテキスト形式で送信
- **リアルタイム同期**: 複数端末から同時閲覧（最大20端末）
- **有効期限**: 7日間（自動削除、延長不可）

### セッション終了

- 画面右下のメニューから終了
- 試合履歴・統計情報はクリア
- 設定値（コート数、人数、アルゴリズム）は次回に引き継ぎ

## アルゴリズム

2つの方式から選択可能:
- **ばらつき重視（discreteness）**: 毎回できるだけ違うメンバーと組む
- **均等性重視（evenness）**: 全員の試合回数をできるだけ同じにする

### 共通の仕組み

- 履歴がない場合（最初の1回目）は完全にランダム
- ランダム選出を何度か繰り返し、その中から最適なものを選出
  - 繰り返す回数は現在のメンバー数によって異なる（チューニング予定）

### 編集距離による類似判定

履歴と似通っているかどうかの判定には編集距離を使用:
- コートとコートに入るメンバーは二次元の数値配列
- コートメンバーの配列は順序が異なっても同じとして扱うため、まず二次元配列を一定の規則に従ってソート
- 二次元配列を flat で一次元配列に変換して、動的計画法により編集距離を求める

### プレイ回数の平準化

複数のランダム選出された配列の中から、もっとも平準化されそうなものを選出:
- 各プレイヤーのプレイ回数の、最大値と最小値の差が一番小さいものを選出
- 最大値と最小値の差が同値のものは、標準偏差がもっとも小さいものを選出
- 遅れて参加した場合は参加時点での他のプレイヤーの参加回数の最頻値を補正値として保持し、計算時にはその値を加算

### 計算量について

このアルゴリズムは、履歴やメンバー数が多くなると指数関数的に計算量が増えます。履歴数が少ない（そんなに何度も試合できない）ことを前提としています。

> このアルゴリズムは暫定です。もっと良いアルゴリズムがあるかもしれないので（コントリビュート歓迎）。

## 制限事項

### 人数・コート

| コート数 | 最小人数 | 推奨人数 |
|---------|---------|---------|
| 1面 | 4人 | 5〜8人 |
| 2面 | 8人 | 9〜12人 |
| 3面 | 12人 | 13〜16人 |
| 4面 | 16人 | 17〜20人 |

- **最大人数**: 32人

### データ保持

- **セッションデータ**: ブラウザを閉じるとリセット
- **共有データ**: 7日間保持後に自動削除

## 対応環境

### ブラウザ

- Google Chrome（最新版）
- Safari（最新版）
- Firefox（最新版）
- Microsoft Edge（最新版）
- iOS Safari
- Android Chrome

### 画面・操作

- **最小画面サイズ**: 320px（iPhone SE対応）
- **推奨**: 375px以上
- **ボタンサイズ**: 最小44×44px（指で押しやすいサイズ）
- **文字サイズ**: 最小14px

### アクセシビリティ

- 色だけでなく形や文字でも区別（色覚対応）
- ブラウザの文字サイズ設定に対応
- キーボードのみでも操作可能

### パフォーマンス目標

- **初回読み込み**: 3秒以内
- **組み合わせ生成**: 1秒以内
- **画面切り替え**: 0.5秒以内
- **ドラッグ&ドロップ**: 遅延なし
